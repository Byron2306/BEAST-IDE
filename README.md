# EdgeK BEAST Public Product Marketing Site

A static, promotional website for EdgeK BEAST built from the uploaded Phase 9.1.5 archive.

## Features

- Animated atmosphere used behind an outward-facing product story
- BEAST command-deck hero without black-backed logo dependency
- Mascot sprite animation using uploaded BEAST frames
- Proof chambers and validation telemetry
- Inference economy inversion section
- Visual-system screenshot gallery
- Launch/documents section

## Deploy

Upload the folder contents to GitHub Pages, Netlify, Vercel or any static host. No backend is required.


## Public polish pass

This version removes internal-facing marketing notes and replaces the black-backed logo treatment with native package assets: BEAST icons, panel frames and cursor glyphs. Copy is now aimed at external adopters: developers, AI teams, researchers and IDE builders who need governed agentic coding.


## Actual Studio Capture Pass

This build uses the real BEAST Studio screenshot (`assets/screens/beast-studio-live.png`) as the main public interface capture and the uploaded BEAST cyber-dragon icon (`assets/beast-studio-icon.png`) as the primary brand mark. The validation telemetry strip has been restyled to avoid the broken thin-frame artefact.
